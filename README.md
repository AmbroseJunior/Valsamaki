# Valsamaki Knowledge Base

Nutrition knowledge base for Valsamaki.app — a Cretan wellness platform built for the *Reimagining eHealth in Crete* hackathon (May 9–10, 2026).

Six CSV files designed for direct import into Supabase/Postgres.

## Data Files

| File | Description |
|---|---|
| `foods.csv` | The 6 Cretan foods with descriptions |
| `health_goals.csv` | The 6 health goal categories |
| `compounds.csv` | Bioactive compounds per food |
| `studies.csv` | Peer-reviewed study extractions (human + non-human) |
| `ui_copy.csv` | Plain-language tourist-facing descriptions |
| `food_health_goals.csv` | Evidence-strength mapping of foods to goals |
| `food_details.csv` | Historical use, flavour profile, and preparation per food |
| `nutrition.csv` | Key nutrients per food with health implications |
